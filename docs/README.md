## Adding documentation

Keep detailed documentation in this directory and add a link to each new page in this index.
Use relative links so the documentation works both in a checkout and on GitHub.

- `systems/`: how engine systems work, their architecture and constraints, such as assets, rendering and networking
- `guides/`: step-by-step workflows for engine users, such as creating a game or cooking assets
- `development/`: build tooling, testing, release procedures and contributor workflows

Create these directories as pages are added. Keep the root README focused on the project overview
and getting started.
